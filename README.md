## 🚀 Projeto em destaque

### FinPilot

Plataforma full-stack de **gestão financeira pessoal e empresarial**, desenvolvida com foco em segurança, arquitetura, experiência do usuário e práticas de produção.

🌐 **Aplicação:** https://finpilotapp.com.br  
💻 **Repositório:** https://github.com/EricCareli/FinPilot  
⚙️ **API:** https://api.finpilotapp.com.br

O projeto conta atualmente com:

- Cadastro e autenticação de usuários
- Autenticação com JWT
- Verificação de e-mail
- Recuperação e redefinição de senha
- Alteração segura de e-mail e senha
- Hash de senhas com bcrypt
- Rate limiting
- Headers de segurança com Helmet
- CORS configurado para produção
- PostgreSQL
- Prisma ORM
- Testes de integração
- GitHub Actions
- CI para front-end e back-end
- Health checks da API e banco de dados
- Deploy em produção
- HTTPS
- Domínio próprio
- Infraestrutura de e-mail transacional
